# MOVIRAQ — онлайн-кинотеатр

Адаптивный статический сайт на HTML, CSS и JavaScript. Работает на GitHub Pages — сборка, сервер и база данных не нужны.

## Что уже работает
- Каталог с карточками, постерами и рейтингами
- Поиск по названию, жанру, году и типу
- Фильтрация по жанрам
- Сортировка по рейтингу
- «Мой список» с сохранением в `localStorage`
- Диалог подробностей фильма и адаптивная мобильная версия
- Клавиша `/` для перехода к поиску

## Публикация на GitHub Pages
1. Создай новый репозиторий на GitHub, например `moviraq`.
2. Загрузи в корень репозитория файлы `index.html`, `styles.css`, `script.js` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
6. Через минуту сайт будет доступен по адресу `https://ТВОЙ-ЛОГИН.github.io/moviraq/`.

Если репозиторий называется `ТВОЙ-ЛОГИН.github.io`, сайт будет опубликован на корневом адресе `https://ТВОЙ-ЛОГИН.github.io/`.

## Как добавить свой фильм
Открой `script.js` и добавь объект в массив `movies`. Укажи уникальный `id`, `title`, `year`, `genre`, `type`, `rating`, `duration`, `description` и прямую ссылку на постер в `poster`.

## Важно
GitHub Pages размещает только статические файлы. В этой версии нет аккаунтов, платёжной системы, базы фильмов или собственного видеохостинга. Окно просмотра — демонстрационное; подключай только официальные трейлеры и видео, на распространение которых у тебя есть права. Изображения загружаются с Unsplash, шрифт — с Google Fonts, поэтому для них нужен интернет.
